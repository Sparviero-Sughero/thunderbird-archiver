# Changelog

## 1.3.0 - 2026-07-31

- Added automatic localization based on Thunderbird's interface language.
- Added catalogs for all locales listed with a Thunderbird language pack.
- Added right-to-left layout support for Arabic, Hebrew, and Persian.

## 1.2.0 - 2026-07-31

- Added English and Italian localization.

## 1.1.0 - 2026-07-31

- Added optional permanent cleanup of old messages in Spam and Trash.

## 1.0.0 - 2026-07-31

- Initial release with automatic and manual archiving.
- Added account selection and preset/custom age thresholds.
